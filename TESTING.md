# Проверки Chat Chronicle

## Параллельный поиск — 0.2.1-beta.1

- Собраны и проверены 18 JAR. Для каждого варианта проверены 19 целей Mixin.
- В изолированном клиенте Minecraft 26.3 / Fabric кандидат прошёл сценарий записи и чтения 624 сообщений, сворачивания повторов, скрытия 301 строки, прокрутки, поиска и перехода к контексту. После перезапуска архив открылся и временное скрытие сбросилось.
- Остальные варианты этой беты проверены сборкой и упаковкой. Результаты визуальной проверки и замера для Fabric 26.3 приведены ниже.

## Интерфейс и время кадра на 26.3 / Fabric

- В отдельном маленьком окне проверены перенос длинной строки и обе кликабельные части. Первая вставила команду в поле ввода, вторая открыла подтверждение для нужной команды. Список подсказок рисовался поверх чата.
- Переключение EN → RU сохранило введённый, ещё не сохранённый интервал. Проверены сохранение ширины 220, высоты 75 и белого счётчика повторов и их применение в HUD.
- В тестовой истории две строки выделены через вызов обработчика Shift+ЛКМ. В игровом окне проверены меню ПКМ, отмена и подтверждение. Удалены четыре выбранных оригинала. Повтор, поступивший после выбора, сохранился. После освобождения места и повторного запуска проверены все семь оставшихся записей в SQLite и журнале.
- В бете подпись `Selected: 2` накладывалась на верхнюю строку списка. В 0.2.1 повторная проверка на Fabric 26.3 подтвердила отдельную область для подписи, работу меню ПКМ и возврат места списку после снятия выделения.
- Для времени кадра использованы копии одного локального мира и архива из 250 000 сообщений. Четыре запуска в порядке 0.2.0 → 0.2.1-beta.1 → 0.2.1-beta.1 → 0.2.0, по 10 секунд с открытым чатом без нагрузки и по 12 секунд с четырьмя полными regex-запросами и 48 записями. Фиксировался интервал между вызовами отрисовки кадров. У каждой версии два прогона.

| Режим | p95 0.2.0, мс | p95 0.2.1-beta.1, мс |
| --- | --- | --- |
| Открытый чат | 7,14–7,26 | 7,18–7,25 |
| Поиск и запись | 7,31–7,37 | 7,35–7,38 |

Разброс между запусками сопоставим с разницей между версиями. Этот сценарий не показывает заметного изменения времени кадра. Сводка и сырые данные сохранены в `.tools/frame-021/`.

- Полный ZIP исходников распакован отдельно; Fabric/26.3 пересобран с тестами. SHA-256 бинарного JAR совпал с основной сборкой на текущей машине и её Gradle-кэше.

- [x] Fabric / 26.3: автоматизированные проверки запуска, мира, сообщений/повтора, ПКМ, поиска/контекста, скрытия/прокрутки и повторного чтения.

## Не блокирует beta, но не подтверждено

- Перенос результатов замера кадров из локального мира на серверные сборки и другие сцены.
- Длительный тест удержания памяти и совместимость с другими модами, заменяющими чат.
- Произвольное переназначение сочетаний и отдельная постоянная история введённых команд пока не реализованы; решение о серверном удалении подписанных сообщений открыто.
- Компактация и первоначальное восстановление индекса используют рабочую очередь архива. Полные поисковые сканирования уже уступают её между порциями. Не выдавать устранение задержки поиска за устранение всех возможных задержек обслуживания.

## Команды

```powershell
.\gradlew.bat build
.\gradlew.bat releaseCheck
```

Обычная сборка не запускает миллионный тест. Приёмку повторять для кандидата или изменений затронутого поведения хранения/поиска; тестовые архивы временные и не используют профиль игрока. Реальная авария моделируется только в специально созданном дочернем процессе.

Для ошибки записать версию JAR, шаги, ожидаемый и фактический результат. Приложить logs/latest.log тестового профиля; личные архивы чата передавать только при необходимости воспроизведения.
