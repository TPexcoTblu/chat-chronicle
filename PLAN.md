# Chat Chronicle — план v0.11

Дата: 2 ноября 2026 года.
Статус: пользователь разрешил разработку. Создана первая alpha-реализация; это не готовый релиз.
Окончательное название проекта — Chat Chronicle.

## Утверждённые требования

1. Minecraft Java 26.3, последний стабильный Fabric Loader. Зафиксированы Loader 0.20.1 и Fabric API 0.165.0+26.3.
2. Один календарный день — одна общая история. День начинается в 00:00 по времени компьютера. Повторные входы отмечаются видимыми разделителями внутри дня.
3. Миры и серверы хранятся вместе, в общей истории. По последнему решению пользователя вход в мир/на сервер отмечается сохраняемой строкой с временем, именем игрока и местом. Это заменяет прежнее решение не добавлять строки о входах.
4. История без лимита количества сообщений и срока хранения по умолчанию. Все сохранённые дни доступны для поиска и просмотра. Предусмотреть настройки ограничений.
5. Обычный чат можно прокручивать через предыдущие дни. Память ограничивается кэшем, история подгружается порциями.
6. Отдельный экран истории со списком дней, количеством сообщений и календарём.
7. Поиск по умолчанию по всему архиву. Выбор конкретного дня или диапазона дат.
8. Обычный поиск по части текста без учёта регистра по умолчанию. Отдельные флажки регулярных выражений, регистра и целого слова.
9. Результаты поиска содержат только совпадения. Переход к результату открывает нужный участок переписки с выбранным сообщением в соответствующий день; выше и ниже можно читать контекст. Не загружать весь архив ради одного результата.
10. Сохранять все сообщения обычного чата с исходным структурированным форматированием, цветами, стилями и интерактивными элементами.
11. Сохранять оригиналы независимо от визуальных дополнений времени, счётчиков и фильтров.
12. Последовательные одинаковые сообщения по умолчанию сворачиваются со счётчиком. Другое сообщение прерывает группу. Сворачивание отключается в настройках.
13. Полный состав контекстного меню Chat Patches по ПКМ; варианты действий организованы подменю.
14. Скрытие только с экрана и окончательное исключение из архива/поиска — разные действия. Удаление с подтверждением.
15. Интервал записи настраивается: ориентир 1–5 секунд, начальное значение 2 секунды. При штатном закрытии сохранить всё.
16. Повреждённые и незавершённые записи не должны приводить к падению игры: пропустить их и сохранить доступ к остальной истории. По возможности отметить повреждённый участок и незавершённый запуск.
17. Настраиваемое время возле сообщения, по умолчанию HH:mm:ss. При наведении — полная дата и время.
18. Предусмотреть сочетания Shift/Ctrl с ПКМ и возможность настройки.
19. Полная локализация интерфейса на английский и русский, английский по умолчанию. Язык мода выбирается независимо от Minecraft.
20. Поддерживать отдельное Markdown-описание для Modrinth при каждой версии, вместе с журналом изменений и отчётом о прогрессе.

## Контекстное меню

Включить весь проверенный состав Chat Patches:

- Копирование текста: обычного, с форматированием, без времени, без счётчика повторов, исходный JSON.
- Копирование ссылок из сообщения.
- Копирование времени, полной даты из подсказки и Unix time.
- Копирование текста и значения счётчика повторов.
- Копирование имени и UUID отправителя, когда эти данные доступны.
- Ответ с заполнением поля ввода по настраиваемому шаблону имени, без автоматической отправки.
- Удаление сообщения.
- Обводка выбранного сообщения; оформление и дополнительные настройки уточняются.

Наши дополнительные действия: показать сообщение в истории с контекстом, скрыть только с экрана.
Начальные сочетания alpha: Shift+ПКМ копирует исходный текст, Ctrl+ПКМ открывает контекст. Оба отключаются в настройках; произвольное переназначение ещё предстоит.

## Технический подход

- Дополняемый журнал с CRC32 каждой записи по пути год/месяц/день. Оригинальный Component JSON хранится отдельно от оформления мода.
- SQLite/FTS5 — восстанавливаемый индекс поиска и постраничного доступа. Повреждение индекса не уничтожает исходный журнал.
- Операции диска и поиск выполняются в рабочем потоке. Отрисовка использует ограниченный кэш и подготовленные строки.
- Индекс обновляется по мере поступления данных; перед запросами видны последние принятые записи.
- Пагинация по идентификатору последовательности, а не поиском совпадения текста. Каждое сообщение имеет собственный UUID.
- Регулярные выражения RE2: без опасного перебора. Неподдерживаемые конструкции нужно объяснять в интерфейсе.
- Удаление отражается отдельной записью tombstone и сохраняется при перестройке индекса. Физическая очистка байтов — отдельный этап.
- Блокировка архива от одновременной записи несколькими экземплярами игры.
- Доступный диск фактически ограничивает объём. Ошибки записи показываются и журналируются; старый архив автоматически не удаляется.

## Состояние alpha.7

Реализованы хранилище, поисковый индекс, восстановление, захват сообщений, экран истории/календарь, загрузка порциями, поиск и контекст, меню ПКМ, время, сворачивание повторов и основные настройки.

В alpha.4 исправлено распознавание повторов при изменяемых серверных click/hover данных; добавлены настраиваемые анимации появления/затухания и Shift-мультивыбор с групповыми действиями. Подтверждение отмены сохраняет текущий экран/выделение; обновление HUD после удаления использует согласованный снимок и сохраняет пришедшие позднее сообщения. Индекс обновлён до схемы 3 с пересчётом групп из оригинальных журналов.
В alpha.5 добавлены сохраняемые разделители входов и полные словари английского/русского интерфейса с переключателем языка. Название Chat Chronicle окончательное. Добавлены MODRINTH_README.md, CHANGELOG.md, RELEASING.md и PROGRESS.md; поддерживать их при каждом обновлении.
Сборка и автоматические проверки выполнены. Клиент запущен и загрузил мод. Визуальная проверка в игре и совместимость с пользовательской сборкой остаются незавершёнными.
Фактические ограничения перечислены в README.md, сценарии проверки — в TESTING.md.

## Критерии готовности релиза

- Нет потери или непреднамеренного дублирования записей в согласованных сценариях.
- Полная история доступна независимо от размера кэша.
- Поиск, переход к конкретному сообщению и просмотр контекста корректны через границы порций и дней.
- Повреждение данных или индекса не приводит к падению игры.
- Нет воспроизводимых вылетов/зависаний в согласованной матрице проверок.
- Влияние на игру и скорость поиска измерены на согласованных объёмах.
- Ограничения и конфликты задокументированы.
