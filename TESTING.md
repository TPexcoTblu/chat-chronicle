# Проверки Chat Chronicle 0.1.0-beta.1

## Уже выполнено

- 31 обычный автоматический тест: сохранение/CRC/восстановление, Unicode и исходный JSON, дневная история, поиск/флаги/даты/пагинация/контекст/отмена, серии повторов, мультивыбор и границы снимка, удаление/лимиты/компактация, кэши, настройки и EN/RU.
- 2 отдельные приёмочные проверки (`gradlew.bat releaseCheck`): 1 000 000 сообщений, 8 страниц за пределами стандартного кэша, точный поиск по дате, контекст, полный regex без совпадений с записью между порциями, перезапуск с сохранением 1 000 001 записей; реальное принудительное завершение дочернего JVM и восстановление с продолжением записи.
- В пользовательском профиле alpha.10: запуск с полной сборкой, HUD и история, ПКМ, run_command в чате и контексте, поиск/переход к контексту, F3+T с последующим чтением истории, повтор ×2.
- В Chat Chronicle Test: творческий суперплоский мир с командами; /tellraw, suggest_command, hover show_text, меняющаяся между кадрами обфускация. Прежний запрет управления отдельным окном Java больше не отражает состояние этих проверок.
- Входы в разные миры и сервер видны в общей истории с сохраняемыми разделителями; утверждение старого списка о том, что разделителей быть не должно, удалено.
- Три spark-профиля alpha.8 на matix.gg и отдельный проверочный профиль alpha.10 сохранены локально. Они не являются A/B-замером ускорения новой beta.

## Короткая оставшаяся ручная приёмка

Каждый сценарий выполнить один раз. После исправления ошибки повторять только затронутый сценарий.

- [ ] **Геометрия и настройки:** маленькое окно/крупный GUI, длинное сообщение с разными кликабельными частями и переносами; подсказки ввода выше чата. Изменить ширину/высоту, цвет счётчика и язык EN/RU, проверить сохранение введённых значений и вернуть исходные настройки.
- [ ] **Мультивыбор в интерфейсе:** выбрать только созданные для теста записи/группу, получить новый повтор после выделения; отменить удаление, затем подтвердить. Новый повтор не входит в старый снимок. После освобождения места и перезапуска удалённые записи не возвращаются. Автоматическая логика уже проверена.
- [ ] **Редкие компоненты:** open_url/copy_to_clipboard, конкретные серверные show_dialog/custom и player-глифы; обычные run_command/suggest_command/hover/обфускация уже проверены.

## Не блокирует beta, но не подтверждено

- Сравнение FPS/времени кадра старой и новой версий при одинаковых сцене, архиве и настройках.
- Длительный тест удержания памяти и совместимость с другими модами, заменяющими чат.
- Произвольное переназначение сочетаний и отдельная постоянная история введённых команд пока не реализованы; решение о серверном удалении подписанных сообщений открыто.
- Компактация и первоначальное восстановление индекса используют рабочую очередь архива. Полные поисковые сканирования уже уступают её между порциями. Не выдавать устранение задержки поиска за устранение всех возможных задержек обслуживания.

## Команды

```powershell
.\gradlew.bat build
.\gradlew.bat releaseCheck
```

Обычная сборка не запускает миллионный тест. Приёмку повторять для кандидата или изменений затронутого поведения хранения/поиска; тестовые архивы временные и не используют профиль игрока. Реальная авария моделируется только в специально созданном дочернем процессе.

Для ошибки записать версию JAR, шаги, ожидаемый и фактический результат. Приложить logs/latest.log тестового профиля; личные архивы чата передавать только при необходимости воспроизведения.
