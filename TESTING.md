# Проверка Chat Chronicle alpha

## Выполнено автоматически

- Сохранение и восстановление сообщений, кириллицы и исходного JSON.
- Общая последовательность с фильтром по дню.
- Обычный поиск, буквальные спецсимволы, regex, регистр, целое слово, диапазон дат, отмена.
- Постраничный доступ и контекст конкретной записи среди одинаковых сообщений.
- Пропуск повреждённой строки и обрезанного хвоста, продолжение записи после восстановления.
- Сохранение удаления после полной перестройки индекса.
- Перестройка физически повреждённого SQLite-индекса из журнала.
- Обнаружение незавершённого запуска и удаление маркера при штатном закрытии.
- Нагрузочный сценарий на 25 000 сообщений: индексированный поиск и загрузка контекста.
- Полные серии из 1000 и 300 повторов с разделителем между ними: счётчики, пагинация групп вперёд/назад, перезапуск и перестройка индекса.
- Удаление представителя группы сохраняет остальные оригиналы и обновляет границы/счётчик.
- Граница дня разделяет одинаковые сообщения; обновление схемы производного индекса сохраняет оригиналы.
- Совместное применение лимитов дней и числа исходных сообщений; по умолчанию они отключены.
- Физическое освобождение места уменьшает журнал; удалённый текст не возвращается после перестройки индекса, новая запись после очистки работает.
- Повреждённый маркер аварии не препятствует чтению здоровой истории.
- Регрессия серверных повторов: разные команды click_event и данные hover_event при одинаковом тексте сворачиваются, разные цвета/тексты/отправители — нет. Исходные JSON сохраняются, обновление индекса пересчитывает группы.
- Мультивыбор: порядок копирования/действий задаётся порядком записей; новая доставка повтора не расширяет ранее выбранный диапазон.
- Групповое удаление 600 сообщений, перекрывающиеся диапазоны, новая доставка после выделения и восстановление после перестройки индекса. Согласованный снимок исходных сообщений и групп после удаления.
- Появление и затухание, прерывание затухания без скачка прозрачности, отключение анимации.
- Полнота английского/русского словарей, одинаковые ключи и аргументы, корректные ссылки из Java, отсутствие жёстко заданных русских строк интерфейса.
- Английский по умолчанию, сохранение русского выбора и возврат к английскому при неизвестном коде языка.
- Переключение языка статуса архива и сохранённых маркеров без изменения исходных записей.
- Дедупликация уведомлений одного соединения и повторные входы; разделители разрывают серии повторов и остаются в общей дневной истории после перезапуска.
- Совпадение версии публичного описания Modrinth, README, CHANGELOG и отчёта с gradle.properties.

## Запуск клиента

Тестовый клиент 26.3 / Loader 0.20.1 / Fabric API 0.165.0+26.3 загрузил Chat Chronicle без ошибки и завершил загрузку ресурсов. Это не подтверждает работу всех элементов интерфейса в мире.
Визуальная проверка не завершена: computer-use вернул `Computer Use was not approved to use java` при выборе отдельного тестового окна Java.
